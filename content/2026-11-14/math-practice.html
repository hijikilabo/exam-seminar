① 少なくとも1枚表｜反対側を数える

再構成問題｜動画 02:29〜02:32

問題：公平な硬貨3枚を、それぞれ独立に投げる。少なくとも1枚が表になる確率を求める。

着眼点：少なくとも1枚は、表1枚・表2枚・表3枚のすべてを含みます。該当する側を数えるより、「表が1枚もない」を除くと簡単です。

表の枚数区別した3枚の結果場合の数
0枚裏裏裏1
1枚表裏裏・裏表裏・裏裏表3
2枚表表裏・表裏表・裏表表3
3枚表表表1
  1. 全体は、各硬貨に表・裏の2通りがあるので2×2×2＝8通り。
  2. 1枚も表が出ないのは、裏裏裏の1通りだけ。
  3. 条件に合うのは8−1＝7通り。
答え：7/8　（または 1−1/8＝7/8）

解の吟味・別解：直接数えれば、表1枚3通り＋表2枚3通り＋表3枚1通り＝7通り。表の枚数0・1・2・3を、等確率の4通りとして扱うと誤ります。

失点ポイント：「少なくとも」を「ちょうど」と読み替えない。全部裏の確率1/8を求めたところで止めず、1から引く。

③ 黒玉が袋に残る｜取り出す玉との違い

再構成問題｜動画 02:32〜02:38

問題：白玉4個・黒玉2個が入った袋から、1個ずつ無作為に、戻さずに2個取り出す。黒玉が少なくとも1個、袋の中に残る確率を求める。

着眼点：求めるのは手元に取り出した黒玉ではなく、袋に残る黒玉です。条件に合わないのは、黒玉を2個とも取り出して袋に残さない場合だけです。

  1. 白玉をA・B・C・D、黒玉をE・Fと区別する。色が同じでも物として区別して数える。
  2. 1個目は6通り、2個目は残り5通りなので、順序を区別した全体は30通り。
  3. 黒玉が残らないのは(E,F)と(F,E)の2通り。
  4. 条件に合うのは30−2＝28通り。
答え：28/30＝14/15
取り出した色の順場合の数袋に残る黒玉
白→白4×3＝122個
白→黒4×2＝81個
黒→白2×4＝81個
黒→黒2×1＝20個

直接数える別解：(12＋8＋8)/30＝28/30＝14/15。4つの色の分類は、12・8・8・2通りなので等確率ではありません。

順序なしの別解：同時に選んだ2個の組で数えるなら、全体6×5÷2＝15組。黒2個の組は1組なので、(15−1)/15＝14/15。分母だけ15、分子だけ順序あり28にしないようにします。

確率を掛ける別解：黒を2個とも取る確率は(2/6)×(1/5)＝1/15。それを1から引いて14/15です。

失点ポイント：「戻さない」ので2回目の分母は5。「残る」と「取り出す」を最初に丸で囲んで区別します。

④ 平均が自然数｜正の偶数に言い換える

再構成問題｜動画 02:38〜02:43

問題：−5、−2、−1、3、6、10が1枚ずつ書かれた6枚のカードから、同時に無作為に2枚引く。2枚の数の平均が自然数となる確率を求める。この問題では自然数を1、2、3、…とする。

着眼点：平均は(a＋b)/2。自然数になるには、a＋bが正の偶数であることが必要です。「和が正」だけでは、半端な平均になる組を入れてしまいます。

全体：6×5÷2＝15組

同時に引くので、(−2,6)と(6,−2)は同じ組です。以下の15組を一度ずつ数えます。

引いた2枚和平均自然数か
-5 と -2-7-7/2×
-5 と -1-6-3×
-5 と 3-2-1×
-5 と 611/2×
-5 と 1055/2×
-2 と -1-3-3/2×
-2 と 311/2×
-2 と 642○
-2 と 1084○
-1 と 321○
-1 と 655/2×
-1 と 1099/2×
3 と 699/2×
3 と 101313/2×
6 と 10168○
該当：{−2,6}、{−2,10}、{−1,3}、{6,10}
答え：4/15

速く絞る別解：偶数は−2・6・10、奇数は−5・−1・3です。平均が整数になるのは、同じ偶奇から2枚選ぶ6組。そのうち、奇数同士の{−5,−1}と{−5,3}は平均が負なので除き、4組とできます。

解の吟味：例えば{3,6}の和は9で正ですが、平均4.5は自然数ではありません。{−5,3}の和は−2で偶数ですが、平均−1は自然数ではありません。2つの条件を分けて点検しましょう。

失点ポイント：カードの−1を＋1と読み違えない。式の2で割ること、和が正であることの両方を確認します。

⑤ 硬貨とくじ｜ルールを8通りに整理する

再構成問題｜動画 02:43〜02:49

問題：公平な硬貨2枚を独立に投げ、表の枚数を数える。別に、当たり1本・外れ1本のくじから1本を無作為に引く。硬貨の結果とくじは独立とする。当たりなら表の枚数×200ポイント、外れなら表の枚数×100ポイントをもらう。ちょうど200ポイントとなる確率を求める。

着眼点：「表の枚数0・1・2」と「当たり・外れ」で6通り、と数えるのは誤りです。2枚の硬貨を区別すると、表1枚は表裏・裏表の2通りあります。

ルールの試し算：表2枚・当たりなら2×200＝400ポイント。問題中の例と合うかを、数え始める前に確かめます。

硬貨1硬貨2当たりの場合外れの場合
表裏200 ○100
表表400200 ○
裏裏00
裏表200 ○100
  1. 硬貨の結果は4通り、くじは2通りなので、全体は8通り。
  2. 表裏＋当たり、裏表＋当たり、表表＋外れの3通りが200ポイント。
  3. 8通りはそれぞれ同じ確率1/8で起こるので、3/8。
答え：3/8

確率を使う別解：表1枚かつ当たりは(1/2)×(1/2)＝1/4。表2枚かつ外れは(1/4)×(1/2)＝1/8。重ならない場合なので足して1/4＋1/8＝3/8です。

失点ポイント：「外れ＝0点」だと勝手に読み替えない。このゲームでは外れでも、表の枚数に応じたポイントがもらえます。

⑥ 正六角形とさいころ｜直径を3種類調べる

再構成問題｜動画 02:49〜02:56

問題：正六角形ABCDEFの頂点を、順に1・2・3・4・5・6と対応させる。公平な大小2個のさいころを独立に投げ、出た目に対応する2頂点と、固定した頂点Aを使う。3点が重なるなどして三角形にならない場合もある。直角三角形ができる確率を求める。

ルール確認：目が2と3ならA・B・Cを使う。1と2ならAが重なり、三角形ができません。大きいさいころと小さいさいころは区別するので、(2,4)と(4,2)は別の結果です。

着眼点：正六角形は円に内接し、AD・BE・CFは直径です。円周角の性質により、直径を一辺とする三角形は直角三角形になります。逆に、この円に内接する直角三角形の斜辺は直径です。

斜辺となる直径大小の目の組場合の数
AD(4,2),(2,4),(4,3),(3,4),(4,5),(5,4),(4,6),(6,4)8
BE(2,5),(5,2)2
CF(3,6),(6,3)2
  1. 全体は、大小それぞれ6通りなので36通り。三角形にならない目も全体に含める。
  2. ADを使う場合、D＝4は必要で、残りはB・C・E・Fの4頂点。それぞれ目の順が2通りなので8通り。
  3. BEまたはCFを使う場合は、固定したAが直角の頂点になる。それぞれ2通り。
  4. 3つの場合は重ならないので8＋2＋2＝12通り。
答え：12/36＝1/3

解の吟味：4と4はDが重なるため不可。1を含むとAが重なるため不可。Aが固定されていても、ADが必ず斜辺になるわけではありません。BE・CFの場合を忘れると8/36にしてしまいます。

失点ポイント：分母を「三角形ができる20通り」に変えない。今回の質問は、さいころを投げた全結果36通りのうち直角三角形になる確率です。

⑦ 残った最小の数｜途中の欄を作って数える

問題：1〜5の数が1枚ずつ書かれた5枚のカードから、1枚ずつ無作為に、戻さずに2枚を取り出す。最初に取り出した数をA、2枚を取り出した後に袋に残った3枚のうち最小の数をBとする。10A＋Bが素数となる確率を求める。

類題・確認問題と詳しい解答

先に問題を解き、答えを開いたら理由も照合しましょう。以下の確認問題は、講義を復習するためにこのガイドで作成したものです。

問1　【①の類題】公平な硬貨4枚で、少なくとも1枚表が出る確率は。
1−1/16＝15/16

全体は2⁴＝16通り。全部裏の1通りだけを除きます。3枚の答え7/8を、そのまま使わず全体を作り直します。

問2　【①の比較】公平な硬貨3枚で、ちょうど1枚表の確率は。
3/8

表裏裏・裏表裏・裏裏表の3通り。「少なくとも1枚」の7/8とは違います。

問3　【③の比較】白4個・黒2個から戻さず2個取り出す。少なくとも1個の黒を「取り出す」確率は。
1−(4/6)×(3/5)＝1−2/5＝3/5

反対は2個とも白を取り出すこと。袋に黒が残る確率14/15とは、問われた出来事が違います。

問4　【④の類題】同じ6枚で、平均が自然数でなく「整数」なら確率は。
6/15＝2/5

同じ偶奇の2枚を選べば平均は整数です。(-5,-1)、(-5,3)、(-1,3)、(-2,6)、(-2,10)、(6,10)の6組。自然数の場合と違い、負の整数となる2組も含めます。

問5　【⑤の類題】同じゲームで、200ポイント以上をもらう確率は。
4/8＝1/2

200ポイントの3通りに、表表かつ当たりで400ポイントの1通りを加えます。条件が「ちょうど200」から「200以上」へ変わった点を確認します。

問6　【⑥の比較】直角かどうかを問わず、三角形ができる確率は。
20/36＝5/9

2個のさいころで、1以外の異なる目が出ると三角形になります。最初は2〜6の5通り、もう一方はその目を除く4通り。全体は依然として36通りです。

問7　【⑦の確認】最初に2、次に1を取り出した。Bと10A＋Bは。

残りは3・4・5なのでB＝3。A＝2より10A＋B＝23で、素数です。2枚目の数1をBにして21としないようにします。

問8　【⑦の類題】同じ取り出し方で、B＝2となる確率は。
6/20＝3/10

1を取り出し、2は残す必要があります。相手のカードは3・4・5の3通りで、その前後を区別すると6通り。全体20通りなので3/10です。

解き直しの進め方

  1. 最初の5分：①か③を選び、「少なくとも」の反対の出来事を一文で書く。
  2. 次の10分：④・⑤・⑦から一つ選び、表を白紙から作り直す。計算より先に列の名前を決める。
  3. 次の5分：⑥の図でAD・BE・CFを指し、それぞれの目の組を説明する。
  4. 翌日：間違えた類題だけを解き直し、前回の誤りを「読み違い・重複・漏れ・計算」のどれかに分ける。
家での確認：「どうしてそう考えた？」「本文のどこ？」「この条件が変わっても同じ？」と、根拠を本人の言葉で説明してもらいます。説明できなかった所だけ、目安時刻に戻って確認しましょう。
